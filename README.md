### RC-01 鎖上の空間最適可逆ペブリングの増大率

可逆計算では中間結果を捨てられないので、消すには逆計算が要る。その代価を捉える
最小の模型が鎖上の可逆ペブルゲームである。空間がちょうど最小のときの時間の増大率
`c` が厳密に決まったという結果と、その証明の筋を解説する。`c = 2^(1+κ*)`
（数値では 2.5170648368938…）。この恒等式は Lean 4 で仮定を持たない形で証明されている。

### RC-02 消去を許した可逆ペブリング

不可逆な消去を有限回だけ許すと、可逆な計算はどれだけ速くなるか。
飽和定理（手数が絶対的な床 `2n-1` に達するのは消去回数が `⌈(n-1)/(p-1)⌉-1` 以上の
ときちょうどである）を、1 ページの数え上げで証明する。
消去とペブルが交換可能な資源でないこと、手数が鎖の長さについて単調でないことも示す。

### RC-03 可逆プログラムは何を払っているか

Janus 系のコーパス 111 本について、生存状態・スタック・時間を同時に実測した資源アトラス。
消去が使われないだけでなく中間結果も片づけられない。書き込みのあった配列の約 65% は
値を 0 に戻す操作を一度も持たない。結果はすべて機械実験であり、定理は主張しない。

## 版と真正性

PDF の内容ハッシュを [SHA256SUMS](SHA256SUMS) に記録している。

```sh
sha256sum -c SHA256SUMS
```

版を改めるときは新しいファイル（`rc01-v1.1.pdf` など）を追加し、旧版は残す。
このリポジトリのコミット履歴が、どの内容がいつ存在したかの記録になる。

```sh
make        # 3 本すべてを組む

```
